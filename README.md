# Portfolio Interactif 3D & Solutions Web

Bienvenue sur le dépôt de mon portfolio professionnel. Ce projet a été développé dans le cadre de mon cursus à Epitech et sert de vitrine pour mes compétences en développement Front-End, intégration WebGL et algorithmes prédictifs.

## Aperçu du Projet

Ce dépôt contient mon portfolio principal ainsi que trois démonstrations de sites vitrines développés pour illustrer ma capacité à répondre aux besoins spécifiques de différents secteurs d'activité (PME, artisans, commerçants).

L'architecture est pensée pour allier performances (optimisation SEO, temps de chargement) et expérience utilisateur immersive.

## Structure du Dépôt

* `index.html` : Le portfolio principal intégrant une scène 3D interactive.
* `style.css` : La feuille de style globale avec implémentation du Glassmorphism.
* `script.js` : La logique d'animation, la gestion de la caméra 3D et l'effet machine à écrire.
* `artisan.html` : Démonstration d'un site vitrine premium pour le secteur de l'artisanat.
* `restaurant.html` : Démonstration d'une interface immersive pour la restauration.
* `barber.html` : Démonstration d'un site à forte conversion pour le commerce local.

## Stack Technique

Les technologies et bibliothèques utilisées dans ce projet ont été sélectionnées pour leur robustesse et leur flexibilité :

* **HTML5** : Sémantique et accessibilité.
* **CSS3 / Tailwind CSS** : Framework utilitaire pour un design responsive "Mobile-First" et rapide à itérer.
* **JavaScript (ES6+)** : Logique asynchrone et manipulation du DOM.
* **Three.js (WebGL)** : Rendu 3D en temps réel pour l'arrière-plan interactif.

## Déploiement Local

Pour visualiser le projet sur votre machine locale, aucune installation complexe n'est requise.

1. Clonez ce dépôt sur votre machine locale :
   git clone git@github.com:Cyrell0/Cyrell0.git
2. Naviguez dans le dossier du projet :
   cd portfolio
3. Ouvrez le fichier `index.html` directement dans votre navigateur web, ou utilisez une extension comme Live Server sur VS Code pour une meilleure expérience de développement.

## Vision et Méthodologie

Formé par la pédagogie par projets, je conçois le code comme un outil de résolution de problèmes. Au-delà de l'intégration visuelle, mon approche intègre le développement de solutions d'Intelligence Artificielle (modèles prédictifs en Python) pour anticiper les comportements d'achat et optimiser la conversion.
